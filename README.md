# Прайс-чекер — Android-приложение: режим ТСД, режим продаж и режим инвентаризации

При запуске открывается выбор режима:

**Режим ТСД** — проверка цен и печать ценников:
- поиск товара по наименованию (выпадающий список подсказок, слова в любом порядке) и по цифрам штрихкода;
- сканирование штрихкода камерой телефона; ручной/Bluetooth-сканер, вводящий цифры с Enter;
- показ наименования, папки, штрихкода, цены и остатка;
- печать ценника на Xprinter XP-365B (TSPL) с текущей датой печати, предпросмотр этикетки;
- загрузка прайса (.xlsx) из общей папки Windows (SMB2/3), автообновление, работа без сети по сохранённой копии.

**Режим продаж** — товарные чеки на время сбоя учётной системы/кассы или отключения электричества:
- поиск товара (название / штрихкод / камера) → окно количества с экранной клавиатурой → товар в чеке;
- позицию можно изменить (количество, цена) или удалить; одинаковый товар суммируется;
- «+ Вручную» — позиция, которой нет в прайсе (название, цена, количество);
- **Принять оплату**: наличные, Kaspi, Halyk и смешанная оплата; расчёт сдачи; быстрые кнопки купюр;
- **Не оплачен**: чек сохраняется с пометкой «НЕ ОПЛАЧЕН» и комментарием (покупатель, телефон);
  оплатить его позже можно из журнала чеков;
- товарный чек: номер (касса-порядковый, например 1-000027), дата и точное время, позиции с количеством,
  ценой и суммой, итог, разбивка оплаты, получено/сдача, статус, продавец, реквизиты магазина;
- чек сохраняется в памяти приложения и картинкой в Галерее (альбом «Чеки»);
- отправка картинки чека в WhatsApp (обычный или Business) с выбором чата, либо в любое другое приложение;
- незавершённый чек не теряется при закрытии приложения.

**Режим инвентаризации** — пересчёт остатков по группам товаров (папкам прайса):
- поле поиска (название / цифры штрихкода) и сканирование камерой;
- на экране: группа, наименование, штрихкод, цена, остаток в учёте и поле «Фактический остаток»;
  кнопка «= как в учёте» подставляет учётный остаток одним нажатием (поле само не заполняется, чтобы не сохранить непосчитанное);
- кнопка **«Сохранить и перейти к следующему товару группы»**: остаток запоминается, открывается следующий ещё не посчитанный
  товар той же папки (в порядке прайса, по кругу). Когда посчитана вся группа, появляется уведомление
  «ВСЕ ТОВАРЫ группы … ИНВЕНТАРИЗИРОВАНЫ»;
- «Пропустить» — перейти к следующему, не вводя остаток; нажатие на строку «Группа: …» показывает список товаров группы с отметками;
  «Ещё…» → «Выбрать группу» — начать с любой группы;
- сеанс сохраняется в памяти телефона: можно закрыть приложение и продолжить позже;
- **«Завершить инвентаризацию»** создаёт Excel-файл **«Остатки ГГГГ-ММ-ДД ЧЧ-ММ.xlsx»** (дата и время окончания сеанса):
  листы «Остатки» (учёт, факт, разница, сумма разницы), «Сводка» (излишки, недостача, итог), «Группы» и «Не посчитано».
  Файл сохраняется в Загрузки / Остатки и его можно сразу отправить кнопкой «Поделиться»;
- **Google-таблица (необязательно)**: каждый телефон добавляет в общую таблицу свой столбец «Остатки <имя продавца>»,
  остатки уходят сразу после каждого сохранения. Несколько продавцов могут работать одновременно, каждый со своего телефона.
  Нет интернета — остатки копятся в очереди и уходят позже. Настройка описана в разделе 5.

**Журнал чеков** — чеки за период (по умолчанию сегодня), итоги: оплачено, наличные / Kaspi / Halyk,
не оплачено, аннулировано; фильтр «только неоплаченные»; аннулирование чека (меню в чеке);
**выгрузка в Excel** за период: листы «Сводка», «Чеки», «Товары в чеках», «Итого по товарам» — для ввода
продаж в учётную систему, когда она заработает. Файл можно отправить или сохранить в «Загрузки».

## 1. Сборка APK через GitHub (без Android Studio)

1. Создайте на GitHub **приватный** репозиторий (рекомендуется: в проекте лежит ключ подписи).
2. Загрузите в него **содержимое** этого архива (папки `app`, `gradle`, `.github`, `keystore`, файлы `gradlew`, `build.gradle` и т.д. должны оказаться в корне репозитория).
   - Через сайт: *Add file → Upload files*, перетащите всё содержимое распакованной папки. Папку `.github` в некоторых системах не видно — включите показ скрытых файлов.
   - Или через git:
     ```
     git init
     git add .
     git commit -m "Прайс-чекер"
     git branch -M main
     git remote add origin https://github.com/<логин>/<репозиторий>.git
     git push -u origin main
     ```
3. Откройте вкладку **Actions** — сборка «Сборка APK» запустится автоматически (5–8 минут).
   Если не запустилась — выберите её слева и нажмите **Run workflow**.
4. Откройте завершённую сборку → внизу в разделе **Artifacts** скачайте `PriceChecker-apk` (zip с файлом .apk).
5. Перенесите .apk на телефон и установите (разрешите установку из неизвестных источников).

Все сборки подписаны одним ключом (`keystore/pricechecker.jks`), поэтому новые версии ставятся
поверх старой без потери настроек. При выпуске новой версии увеличьте `versionCode` в `app/build.gradle`.

Сборка на компьютере: откройте папку в Android Studio (Hedgehog или новее) и нажмите *Build → Build APK(s)*,
либо выполните `./gradlew assembleRelease` (нужен JDK 17). APK: `app/build/outputs/apk/release/`.

## 2. Настройка компьютера с прайсом и принтером (Windows 10/11)

**Общая папка с прайсом**
1. Положите файл прайса в папку, например `C:\Прайс\прайс.xlsx` (ежедневно перезаписывайте его с тем же именем).
2. Свойства папки → *Доступ* → *Расширенная настройка* → *Открыть общий доступ*, имя ресурса, например `Прайс`.
   В *Разрешениях* дайте пользователю право *Чтение*.
3. Узнайте IP-адрес компьютера (`ipconfig` в командной строке) — желательно закрепить его в роутере.
4. Путь для приложения: `\\192.168.1.10\Прайс\прайс.xlsx`.

**Общий принтер XP-365B**
1. Установите драйвер Xprinter, принтер должен печатать с компьютера.
2. *Параметры → Принтеры → XP-365B → Свойства принтера → Доступ* → *Общий доступ к этому принтеру*.
   Имя ресурса без пробелов, например `XP365B`. Путь для приложения: `\\192.168.1.10\XP365B`.
3. Принтер должен работать в **режиме этикеток (TSPL)** и быть откалиброван по зазору между этикетками
   (см. инструкцию принтера / утилиту Xprinter).

**Учётная запись.** Windows 10/11 по умолчанию не пускает «гостя» по сети. Укажите в приложении
пользователя Windows **с паролем** (можно создать отдельного локального пользователя, например `scanner`,
и дать ему доступ к папке и принтеру). Пользователь с пустым паролем по сети работать не будет.

**Сеть.** Телефон и компьютер должны быть в одной сети (Wi-Fi). В брандмауэре Windows должен быть
разрешён «Общий доступ к файлам и принтерам» (порт 445) для частной сети.

## 3. Настройка приложения

Меню → **Настройки**:
- *Сетевой путь к файлу* — `\\192.168.1.10\Прайс\прайс.xlsx` (кнопка «Обзор папки…» позволяет выбрать файл);
- *Пользователь / Пароль* — учётная запись Windows (можно в виде `ИМЯПК\пользователь`);
- *Загрузить по сети* — проверка и первая загрузка;
- *Принтер* → «Общий принтер Windows (SMB)» и путь `\\192.168.1.10\XP365B`;
- *Параметры этикетки*: по умолчанию 58×40 мм, зазор 2 мм, 203 dpi. Укажите размер ваших этикеток;
- *Тестовая печать* — проверка.

На главном экране «Обновить» перезагружает прайс с компьютера. При запуске прайс обновляется
автоматически (можно отключить). Если сеть недоступна, используется сохранённая копия.

**Режим продаж** (Настройки → «Режим продаж и товарный чек»):
- *Номер кассы* — на каждом телефоне свой (1, 2, 3…), чтобы номера чеков не совпадали;
- *Продавец*, *Название магазина*, *БИН/ИИН*, *Адрес*, *Телефон*, *Текст внизу чека* — печатаются в шапке и подвале чека.

Важно: чеки хранятся на телефоне. При удалении приложения или сбросе телефона они пропадут —
регулярно делайте выгрузку в Excel. Обновление приложения поверх старой версии данные сохраняет.

## 4. Если что-то не так

| Проблема | Решение |
|---|---|
| «Неверный логин или пароль» | Проверьте пользователя Windows; для локальной учётки укажите домен = имя компьютера |
| «Нет связи … порт 445» | Телефон в той же сети? IP верный? Разрешите общий доступ в брандмауэре |
| «Компьютер не найден» | Используйте IP-адрес вместо имени компьютера |
| «Не является общим принтером» | Проверьте имя общего ресурса принтера (Свойства → Доступ) |
| Задание уходит, но принтер молчит / печатает иероглифы | Свойства принтера → *Дополнительно* → снимите «Включить дополнительные возможности печати»; убедитесь, что принтер в режиме этикеток (TSPL) |
| Печатается негатив (чёрный фон) | Включите «Инвертировать» в настройках |
| Изображение смещено или перевёрнуто | «Сдвиг X/Y» (в точках, 8 точек = 1 мм при 203 dpi), «Повернуть на 180°» |
| Печать на 2 этикетки / пропуски | Проверьте размер и зазор этикетки, откалибруйте принтер |
| WhatsApp не открывается | Должен быть установлен WhatsApp или WhatsApp Business; иначе откроется выбор приложения |
| Чек не появился в Галерее (Android 9 и ниже) | Разрешите приложению доступ к памяти при запросе |
| Приложение закрылось с ошибкой | При следующем запуске появится окно с текстом ошибки — нажмите «Копировать текст» и перешлите разработчику |
| Файл .xls не читается | Пересохраните прайс как .xlsx (из 1С — «Лист Excel 2007 (*.xlsx)») |

Альтернативные способы печати: «Сетевой принтер по IP (9100)» — если у принтера есть сетевой порт
(или настроен сервер печати); «Системная печать Android» — через установленную службу печати.

## 5. Режим инвентаризации: настройка Google-таблицы (необязательно)

Без этой настройки инвентаризация работает полностью: остатки сохраняются на телефоне и в Excel-файл «Остатки».
Google-таблица нужна, чтобы остатки со всех телефонов сразу были видны на компьютере.

Делается один раз, примерно 10 минут:

1. Откройте **sheets.new** (создастся пустая Google-таблица) и назовите её, например, «Инвентаризация».
2. Меню **Расширения → Apps Script**. Удалите весь код в окне и вставьте содержимое файла
   `google-apps-script/Code.gs` из этого проекта.
3. В первой строке кода замените `ЗАМЕНИТЕ_НА_СВОЙ_КЛЮЧ` на свой секретный ключ (любые буквы и цифры,
   например `Magazin-2026-xk7`). Нажмите значок дискеты (сохранить).
4. **Развернуть → Новое развертывание → тип «Веб-приложение»**:
   - «Выполнять от имени»: **Я**;
   - «У кого есть доступ»: **Все** (Anyone).

   Нажмите «Развернуть» и разрешите доступ к таблице (Google предупредит, что приложение не проверено:
   «Дополнительно → Перейти…» — это ваш собственный скрипт).
5. Скопируйте **URL веб-приложения** (заканчивается на `/exec`).
6. На каждом телефоне: **Настройки → «Инвентаризация: Google-таблица»**: вставьте URL и тот же секретный ключ,
   нажмите «Проверить соединение» (должно появиться «Соединение установлено»).
   Имя продавца берётся из поля «Продавец» в настройках режима продаж.

Как это работает:
- Скрипт создаёт в таблице лист **«Инвентаризация»**: Папка, Наименование, Штрихкод, Цена, Остаток в учёте
  и по одному столбцу **«Остатки <имя>»** на каждого продавца. Служебный столбец A (ключ товара) скрыт, не удаляйте его.
- По желанию, до начала: на одном телефоне «Ещё…» → «Подготовить Google-таблицу» загружает в таблицу весь список товаров
  в порядке прайса. Тогда продавцы заполняют готовые строки, а не создают их по мере подсчёта.
- Если продавец проводит инвентаризацию повторно под тем же именем, его столбец обновляется. Для новой инвентаризации
  переименуйте лист «Инвентаризация» (например, в «Инвентаризация 11.2026»): скрипт создаст новый пустой лист.
- Используйте разные имена продавцов на разных телефонах, иначе они будут писать в один столбец.
- Ключ защищает таблицу от чужих записей: никому его не передавайте. Адрес `/exec` без ключа данные не принимает.
- Обновили скрипт? Нужно заново: «Развернуть → Управление развертываниями → ✎ → Новая версия → Развернуть»,
  иначе будет работать старый код.

## Устройство проекта

```
app/src/main/java/kz/pricechecker/
  LauncherActivity.java    стартовый экран выбора режима
  MainActivity.java        режим ТСД: поиск, карточка товара, печать ценника
  SalesActivity.java       режим продаж: формирование чека
  PaymentActivity.java     приём оплаты (наличные / Kaspi / Halyk, смешанная, сдача)
  ReceiptActivity.java     просмотр чека, WhatsApp, оплата позже, аннулирование
  ReceiptsActivity.java    журнал чеков, итоги, выгрузка в Excel
  SalesDb.java, Receipt.java   хранение чеков (SQLite) и модель чека
  ReceiptRenderer.java     картинка товарного чека
  SalesExporter.java, XlsxWriter.java   выгрузка продаж в .xlsx
  ShareFiles.java          отправка файлов в другие приложения, сохранение в Галерею/Загрузки
  ScanActivity.java        сканер штрихкодов камерой (камера + ZXing)
  App.java                 запись текста ошибки при аварийном закрытии
  SettingsActivity.java    настройки
  SmbBrowserActivity.java  обзор общей папки
  XlsxReader.java          чтение .xlsx без сторонних библиотек
  PriceRepository.java     хранение прайса в памяти и поиск
  PriceLoader.java         загрузка из сети / с телефона
  SmbHelper.java           SMB2/3: скачивание файла, список папок, печать на общий принтер
  LabelRenderer.java       рисование ценника (наименование, цена, штрихкод, дата)
  Tspl.java                формирование задания TSPL (растр BITMAP)
  LabelPrinter.java        отправка на принтер (SMB / TCP 9100 / система Android)
```

Библиотеки: ZXing core (распознавание и генерация штрихкодов), smbj + BouncyCastle (SMB).
Шрифты DejaVu (свободная лицензия) встроены для одинаковой печати кириллицы и знака ₸.

Безопасность: пароль Windows хранится в настройках приложения на телефоне. Используйте отдельную
учётную запись с правами только на чтение папки прайса и печать.

Режим инвентаризации: `InventoryActivity` (экран), `InventoryLogic` (группы и переход к следующему товару),
`InventoryDb` (хранение сеансов и остатков), `InventoryExporter` (Excel «Остатки»), `SheetSync` (отправка в Google-таблицу),
`google-apps-script/Code.gs` (скрипт для таблицы).
